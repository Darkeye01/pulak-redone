## ✨ Key Features

-   **🤖 Gemini AI Insights**: Personalized financial advice and spending trend analysis.
-   **📑 Professional Statements**: Generate official "First Bank of Cash Tracker" statements with PDF download.
-   **🔄 Cloud Pulse Sync**: Real-time multi-device synchronization using Google Drive's hidden App Data folder.
-   **📊 Dynamic Visuals**: Beautifully animated charts and multiple "Scenes" (Dashboard Themes).
-   **🔒 Privacy First**: All data is stored in your own Google Drive or local storage; no external database used.
-   **📱 Fully Responsive**: Seamless experience on mobile, tablet, and desktop.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/yourusername/cash-tracker.git
cd cash-tracker
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env.local` file in the root directory and add your credentials:
```env
API_KEY=your_gemini_api_key_here
GOOGLE_CLIENT_ID=your_google_cloud_client_id_here
```

- **Gemini API Key**: Obtain from [Google AI Studio](https://aistudio.google.com/).
- **Google Client ID**: Obtain from [Google Cloud Console](https://console.cloud.google.com/). Enable **Google Drive API** and configure the OAuth consent screen.

### 4. Run Development Server
```bash
npm run dev
```

## 🏗️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS
- **Icons**: Lucide React
- **Charts**: Recharts
- **AI**: @google/genai (Gemini 3 Pro)
- **PDF/Excel**: html2pdf.js, XLSX
- **Storage**: LocalStorage + Google Drive API (for Cloud Sync)

## 🌐 Deployment (Netlify Friendly)

This project is optimized for Netlify. Simply connect your GitHub repository to Netlify, and it will automatically:
1. Run `npm run build`.
2. Deploy the `dist` folder.
3. Handle SPA routing via the included `_redirects` file.

*Remember to set your `API_KEY` and `GOOGLE_CLIENT_ID` in the Netlify "Environment Variables" settings.*
